# 마리음 아키텍처 자산

조직 대표 README의 서비스 아키텍처를 Archify로 생성했습니다.

- `marieum-architecture.svg`: GitHub README용 벡터 이미지
- `marieum-architecture.png`: 정적 이미지
- `candidate.json`: Archify 재생성용 시스템 설명 원본
- `marieum-architecture.html`: 내려받아 브라우저에서 탐색하는 인터랙티브 원본

공개 저장소에서 확인한 서비스 책임과 통신 흐름을 바탕으로 한 시스템 설명입니다. 로컬 코드 전체를 자동 검증한 결과나 현재 운영 배포를 증명하는 자료는 아닙니다.

정확도 모드의 전사·추천·선택과 실시간 모드의 ASR 중계·TTS를 구분합니다. 실시간 기본 경로에는 LLM 추천·교정을 표시하지 않습니다.
